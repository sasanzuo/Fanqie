续稿从赴临川的周末观察、周一复盘开始：陆蔓失去本专题对外沟通职责，受到书面警告，但保留岗位和原贡献；许与叶完成《衣物的余生》。随后两人共同开发新系列，许与季斐建立知情的性与采访资源交换，拿到采访后仍须靠自己的工作做成内容。
