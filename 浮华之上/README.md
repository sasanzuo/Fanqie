## 当前设定

- 约22—26万字、100章，五卷结构；第一卷已列20章情节任务。故事跨四年，女主约35岁成为主编。
- 女主31岁、普通本科、地方都市报娱乐文化版九年经验，经集团推荐与主编面试入职。
- 女主聪明、隐忍、有手段、有野心，会伤害别人，也会愧疚，但不会轻易退出竞争。
- 对手有独立利益和判断；冲突来自信息、资源、权限与取舍，避免降智推进。
- 职场为主体，感情与项目、人事、合作关系交织；出版单位负责采编，独立经营线负责商业签约及回款，女主不背广告销售任务。
- 男女主由双方知情的身体与利益交换开始；季斐提供能实际协调的稀缺采访、拍摄机会，女主仍须完成编辑交付，后续产生真实感情。
