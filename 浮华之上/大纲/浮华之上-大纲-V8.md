# 《浮华之上》长篇小说大纲

创作大纲 V8｜2026年10月23日｜160章、约21万字重新分章版

## 一、本版采用的尺度

**全书按160章规划，总字数以20—22万字为目标，预算中值约21万字。增加的是断章和阅读节奏，不是故事体量。** 用户最新要求优先于旧版每章1500—2000字的约定，也取代原22—26万字目标；不采用“180章、27—36万字”的扩写方案。

按160章计算，平均每章约1250—1375字。多数章节写1100—1500字，必要的完整交锋可到1600—1800字；少数确有自然落点的短章可在1000字左右结束。字数按正文统计，标题不计，最终以发布时统一口径复核。不能为了达标补动作、重复解释，不能为了多一章在一句话或一个未发生变化的场面中间硬切。

章节任务表中的每一行是一个叙事单位，不要求一章只发生一件小事，也不要求一行中的全部内容均匀展开。同一事件可以连续两三章，但每章应发生新的争取、阻挠、发现、选择或结果；普通通知、等回复、转发邮件、核对版本不单独成章。起稿发现相邻章节没有各自的变化，就合并，允许最终章数在150—170章内自然调整，总字数仍守住20—22万字。

## 二、故事核心与必须兑现的变化

许照宁31岁，普通本科新闻专业，在临川都市报做了九年娱乐文化报道，来到海州的《浮华》做资深人物编辑。她擅长采访、核实和判断人，也懂得抢机会；缺少时装视觉与整刊管理经验，需要在四年的工作里真正补足。

她不靠“比所有人都专业”获胜。前期拿得出采访，后来能组织专题，再能管理不同专业的人，最后才具备整刊管理资格。她的同一项能力也会变质：最初替受访者纠正被剪平的意思，后来选择性地讲述梁的贡献，为自己换取权力。

她聪明、隐忍、好胜、有手段，也会快乐、虚荣、想被爱。她可能在真正有其他选择时主动伤人；后悔不会自动使她交还职位。她和季斐由知情的性与利益交换开始，后来有真感情，双方都对关系中的伤害负责。结局不靠受害者原谅她来证明她值得成功。

### 开篇三次胜负，各自解决不同问题

1. **岑音救稿：争一个能发表、又没有歪曲人物的版本。** 梁有最后期限与备用稿；陆有三个月前期投入；演员不接受被写成“失奖后已经不在乎”。许拿出新判断，争主问和实际贡献署名，陆认真合作。获救不是所有人突然变好，而是各方作出具体让步，许得到可见的认可和下一次机会。
2. **临川展回忆：说明推荐从何而来。** 许起初只是拿正常车马费、受邀回去发活动通稿的地方记者。现场有人将原约的戏服访谈包装成品牌推荐，演员拒绝后，又向媒体放出“临时加价”的说法。许顶住让她照发通稿的压力，采访、核实并推动有权人员纠正现场呈现，最终拿到老演员专访，回报社争得半个版面。程看见的是持续核实、承压及成稿能力，不是一句聪明的提醒。
3. **陆蔓设局：保住共同成果的同时，故意让许交不出自己的部分。** 陆在救稿之后感到威胁，裁剪合影传播性暗示，再借分工尚待确认的说法，阻断顾见秋向许提供新增材料，保留叶的原稿。许查到具体干预，反击后取得项目的明确对接职责；这不等于查明了所有黄谣，更不等于直接升任整个人物组负责人。

前三十章不能全写成别人害她、她被迫反击。独立系列机会出现后，她会主动争走叶本可共同主导的部分，第一次让读者清楚看见：她知道朋友会损失什么，还是接下了更好的安排。

## 四、逐章规划

章名为工作标题，起稿可改。下列160章已经替换V7“原任务整体顺延”的暂编号。每章尽量落到人物的动作、选择或结果；生活章同样有关系或情绪变化，不承担硬塞工作线索的义务。

### 第一卷：先让他们记住她（1—30章，约3.9万字）

**六个月。从外来编辑到有自己专题的人。** 前五章完成救稿的第一次胜负，不把整个共同交付写成同事陷害。第十三章起直接让读者看见陆动手，随后以实际受阻和反击兑现。

| 21 | 一起做的题 | 叶和许从衣物采访延伸出创作者转折的系列，两人都有具体投入，叶期待共同主导。许看到共同成绩不利于独立职责，准备先拿下一个稀缺人物；合作愉快中已经有她不说的盘算。 |

| 23 | 她可以再等 | 梁支持提案但不保证资源，常规路径是继续做别的内容、等下次。季表达私人兴趣并说明能影响的具体采访安排，许清楚自己不会因此失去生计，却不想错过半年一次的职责调整。 |
| 24 | 她答应的事 | 许与季明确性与私人陪伴换取有限采访优先的条件，双方知情、自愿，也有欲望。季不能许诺封面或升职；亲密与不对等利益都真实发生，不写成空泛“各取所需”的一句旁白。 |
| 25 | 给了机会也不是白送 | 季兑现已确认的时间和拍摄范围，受访者仍拒绝安全问题。许靠准备追出具体创作分歧，陈和制作人员守住自己的专业要求；拿到素材是她的工作，不会使资源来历自动正当。 |
| 26 | 她想单独署上名字 | 采访形成可用成稿，许向闻提出独立系列，选择性强调叶方案的不确定性、弱化共同开发。闻接受她的分工建议，给叶保留原篇和署名，却把后续系列主导交给许；读者清楚叶实际失去什么。 |
| 27 | 你可以先告诉我 | 叶当面说明自己本来期待的分工，要求原有贡献和素材使用边界。许承认自己提前争取过，不假称叶也会受益；她有机会拒绝新安排，仍决定留下它，两人的交往从此少一层坦诚。 |
| 28 | 不是每次都为采访 | 许与季第一次在没有工作请求的夜晚仍想见面，做饭、欲望和虚荣都进入关系。她同赵佳补过一次普通周末，也会被笑衣服买贵了；快乐不靠她先接受惩罚才配拥有。 |
| 29 | 后面还得有人做 | 用几个月的试行串起下一次交付，不重写同一套采访流程。许经历一次安排失误并调整带人方法，完成第二期系列，证明她能持续做成，不是只靠一个季提供的人物。 |
| 30 | 她有了自己的一块 | 许取得独立专题职责和有限人员支持，考核来自内容、编辑与组织交付。叶不来私人庆祝，苏仍留下帮忙，季发来亲密消息；这次成功同时留下真实喜悦、欠情与下一阶段责任。 |

**卷末状态：** 许还不是组长或副主编；陆仍在单位，黄谣没有彻底消失；叶仍能认真合作，但不再默认许会照顾双方利益。首次独立成绩与第一次主动背叛同时成立。

### 第二卷：她开始决定留下谁（31—62章，约4.1万字）

**随后十个月。从独立专题到人物专题负责人。** 年度内容只是一个完整项目，不拆成多个重复活动。成长、恋爱和苏的去留穿插推进，真正的伤害是许在有取舍余地时不为苏继续争。

| 章 | 工作标题 | 主要场景、变化及落点 |
| --- | --- | --- |
| 31 | 第一张排期 | 年度人物特别刊启动，许第一次给多人安排工作。苏要求参与影像制片学习，许答应推荐和给实践，不许诺自己无权决定的正式岗位。 |
| 32 | 别替我答应 | 许为抢人物时间先报了过紧档期，任舒指出制作根本做不到。她当场收回一项承诺，失去一个好时间，却第一次把专业分工落到自己身上。 |
| 33 | 不好看的漂亮方案 | 梁与邵岚否定许用华丽造型遮住人物的构想，拿具体图片说明问题。许提出以人物行动连接影像的新办法，保住内容主导，接受视觉决定权不全在自己手里。 |
| 34 | 她也想被看见 | 苏完成一次小规模拍摄安排，发现自己的名字被当作普通助理略过。许要求按实际工作体现贡献；苏因此更相信，这个上司愿意带自己往前走。 |
| 35 | 先到先得也会变 | 封面人物另一刊拍摄调整，团队想挤掉《浮华》的原时间。许用已确定的内容价值争回部分时间，不要求演员取消所有其他合作，代价是放弃一个原想保留的场景。 |
| 36 | 陆蔓的条件 | 陆掌握一条能补专题的人物关系，愿出面但要求清楚署名和职责。许接受一次真正互利的合作，没有逼她再为旧事表态，也没有把她所有顾虑都当陷害。 |
| 37 | 陈叙不欠她的 | 陈先履行已承诺的拍摄，拒绝因旧情为许抢档。许改安排、按正常预算请人；两人吃顿饭说旧事，读者知道他们真的爱过，也真的有分开的理由。 |
| 38 | 不谈工作的一天 | 季和许出门短途休息，争餐厅、拍难看的照片、在陌生地方亲密。他不再只为交换见她，她也开始在未拿到任何资源时想念他。 |
| 39 | 你今天会来吗 | 一次没有利益请求的失约让季不快，许也不愿每次按他的时间走。两人把期待说开，决定正式恋爱和排他，关系第一次有了超出交易的承诺。 |
| 40 | 换个人对接 | 双方按虚构机构规则申报现阶段关系，调整直接工作对接。有人问起最初何时开始，许的回答保留了有利边界；现在处理了关联，不等于过去已经没有问题。 |
| 41 | 别替她付账 | 许与赵佳逛街，季的消费习惯进入她的生活，两人为朋友聚会谁付款闹别扭。赵佳有自己的班级和休假烦恼，许这次真的听完，不把场景变成爱情咨询。 |
| 42 | 她终于单独跑一场 | 苏负责一场已划定范围的人物拍摄，任舒留出求助渠道。她处理了受访者临时情绪，现场有实际成绩，许开始向人力认真提出后续培养安排。 |
| 43 | 谁的时间先改 | 商业活动临时调整，挤到已约好的采访及拍摄。唐管活动合同、许管采编安排，各自争取，最终让出的是一段现场便利，不能一句“都是公司项目”免除代价。 |
| 44 | 一次可以不问吗 | 许为保人物档期同意压缩确认，苏漏掉关键版本，带错拍摄安排。当天不得不返工，受访者失去耐心；错误来自具体决定，不是凭空设置的助理闯祸。 |
| 45 | 当场把它做完 | 任舒接住现场制作，许向人物方承认安排问题，调整问题和场景完成可用采访，苏处理善后。项目得救，但多出的费用和他人的劳动不能用一声辛苦抹掉。 |
| 46 | 错不能只算她的 | 复盘用短场面交代：苏漏核，许压缩时间，两者都记入。许没有把全部责任推给助理，仍因此被要求证明自己能否稳定带队。 |
| 47 | 下班之后还坐着 | 苏怕前途没了，许与她谈后续训练，而非空口保证保岗。苏回去后开始补制作能力，许留下改管理安排；两人的信任仍在，使后来的失望有重量。 |
| 48 | 一顿晚饭不够用 | 叶与周过普通纪念日，一个赶稿、一个想换工作，仍会认真哄对方。叶说起自己的新栏目，周不是她的资源包，两人先有真实好日子再谈后来的异地。 |
| 49 | 只剩这些名额 | 年度投入收紧，人力说明下阶段不新增制片岗，现有资源要在成熟制作和内容岗位之间选择。苏可以保留助理岗；许听见的不是“必须辞掉她”，而是自己还愿不愿争。 |
| 50 | 谁现在不能少 | 任舒证明自己能承担许暂时替不了的制作，另一关键编辑也有具体任务。许开始计算保住谁对团队最有利；想继续培养苏，就要少留一项自己重视的内容或另争预算。 |
| 51 | 她没有开口到底 | 在岗位讨论中，许提出过苏的成长，最后支持保成熟制作与关键编辑，未拿自己那份资源继续争。会后她知道“已经提过”不等于“没有别的办法”。 |
| 52 | 你怎么不早说 | 苏从实际安排看出转岗无望，直接问许何时作了选择。许说明资源，苏指出自己需要的是及时知道；争执落在被信任的人隐瞒了决定，不是苏天真地要求必然升职。 |
| 53 | 她可以不留下 | 人力提供助理现岗，苏考虑薪水和发展，也听到其他机会。许希望她留下做熟悉的执行，苏第一次拒绝用感谢来决定自己的去向。 |
| 54 | 她自己收走的东西 | 苏选择协商离开，费用与交接正常处理。收拾工位时有人帮忙也有人冷淡，许想解释得更好听，最后只能确认工作证明与真实贡献，不把补偿写成宽恕。 |
| 55 | 不是庆功宴 | 特别刊上线、出刊，许带队得到认可，聚餐却空出苏的位置。陆照常谈下一项工作，叶不替许圆场；团队不会因为一个人离开就停止，也不会因此毫无痕迹。 |
| 56 | 他说他理解 | 季理解许选择成熟岗位的理由，带她过一个轻松晚上。两人都有把事业放前面的经验，以为理解就足以免去伤害，还没想到自己也会成为对方的取舍对象。 |
| 57 | 人物组的新安排 | 许凭持续内容与组织成绩成为人物专题负责人，明确分工、人员和汇报关系。闻给资源也要求更深忠诚，梁提醒她接下来不能只会写人物。 |
| 58 | 第一次管到她 | 新分工使陆需要在部分工作上听许安排。陆用实际难题检验她，许给出可执行范围，不借职权羞辱；两人建立有限合作，旧事不因此一笔勾销。 |
| 59 | 带回家的一本刊 | 许回临川看家人，听见他们有与她升职无关的旅行和生活计划。她既享受被夸，也嫌解释工作麻烦；短暂返乡让城市迁移的得失具体，而不是安排家庭灾难催她成熟。 |
| 60 | 梁映真的夜里 | 梁带许看一场视觉制作的最后成形，谈自己真正想做的杂志。许看见能力和野心，第一次真心希望跟着她做更大的作品，不只是借她上升。 |
| 61 | 一张新名片 | 苏靠自己的积累取得外部制作机会，开始新阶段；后续正式加入梁的工作室须等其成立并另谈岗位。许收到工作联系，发现称呼和报价都变了，不能再像过去随手安排。 |
| 62 | 她要的还不止这些 | 许获邀参加更长期的编辑计划，岗位已稳，却看到真正的决定权仍在闻和梁手里。她接受梁提出的跨组合作，第二卷以一段值得期待的联盟结束。 |

**卷末状态：** 许能带固定内容线，正式权责与V7相同；苏离开的原因、选择和去处均成立，不因一次失误就被赶走。男女主有了足够的日常和信任，后续背叛才有感情代价。

### 第三卷：她也会替别人下定义（63—98章，约4.7万字）

**随后十四个月。从人物负责人到副主编。** 梁与许先真正做成作品，再发生分歧、权力竞争与隐瞒；不让读者只听说她们曾经感情好。继任竞争与男女关系用同一套真实人员变动连接，减少另造事件。

| 章 | 工作标题 | 主要场景、变化及落点 |
| --- | --- | --- |
| 63 | 一起做一期 | 梁提出整期方向，许负责跨组人物与文字统筹。叶带独立专题，彼此先说清职责；这是许第一次必须考虑不同栏目能否组成一本杂志。 |
| 64 | 她看不懂的那张图 | 许误判时装表达，邵岚和时装编辑提出更有力方案。她学会问具体目标、选择专业意见，保住人物叙事，不靠突然获得超强审美压过所有人。 |
| 65 | 改哪一项 | 两个栏目抢同一制作资源，许不能靠同时答应取悦双方。她选一项先做，给另一项实在替代，第一次承受来自自己团队的合理不满。 |
| 66 | 梁替她挡了一次 | 外部提出会扭曲报道的修改，梁承担压力拒绝，保住许的内容。许看见保护不是空话，之后主动替梁争取一项必要制作，联盟有双方付出。 |
| 67 | 叶的名字在前面 | 叶的独立专题成形，许按实保留其主导，不把所有成果收进自己名下。两人重新能合作，却不回到过去无话不说的状态。 |
| 68 | 今晚不带电脑 | 许与季为了能否完整休息吵一小架，最后仍有一段亲密日常。两个人会笑也会烦，不能让所有同居片段都提前预告职业决裂。 |
| 69 | 不是更贵就更好 | 一项拍摄成本超出预想，梁想保效果，许提出减少一处场景但保留核心人物行动。双方各退一步完成制作，既写冲突也写彼此真的能互补。 |
| 70 | 整本都得算 | 许处理跨栏目衔接与一次实际内容缺口，杜若守住出版节点。常规审校一笔带过，主要写许舍掉自己偏爱的段落，第一次让整期高于个人篇章。 |
| 71 | 这本是我们做的 | 整期获得具体读者反响和专业认可，团队庆功。梁认真谈未来接班时愿给许的职责，许动心；她们相信合作有明天，而非从第一天就在互相欺骗。 |
| 72 | 她也可以搬走 | 许考虑换更好的住处，季想参与决定，两人把不同生活习惯摊开。她既享受共同生活，又想留下自己的空间，埋的是关系要求，不是故弄玄虚的预兆。 |
| 73 | 先问她愿不愿意 | 闻准备争集团内容职位，继任进入实际讨论，梁提出自己的整刊方向。许听见自己可得到的安排，也听见重要创意仍由梁决定，开始衡量继续跟随是否足够。 |
| 74 | 韩序的那本杂志 | 跨刊交流让许直接看到韩的成品和团队能力。韩对内容、平台与人才有具体办法，程也认可；竞争不再只是内部谁更受主编喜欢。 |
| 75 | 空降的消息 | 外界传方蘅将任主编，许发现自己也会被传言牵着走。她去问实际谈判内容，而非发动人情找一个泄密者，确认谈的主要是视觉创意岗位。 |
| 76 | 她有她的条件 | 方说明独立团队、权限和投入条件，与集团某方案不合。她退出这一合作，保留其他创作；许少一个假想敌，却明白高位不会因对方退了就自然落到自己头上。 |
| 77 | 推荐过不等于选定 | 许向程探问未来，程让她比较整刊能力，明确韩是可行人选。她第一次确认原来的推荐不是长期保险，开始决定要不要绕过梁争更大空间。 |
| 78 | 最擅长创意的人 | 内部说明中，许赞梁“创意不可替代”，却把整期组织贡献更多归给自己。没有造一份假材料，选择性的讲述仍改变了他人对梁适合管什么的判断。 |
| 79 | 她知道少说了什么 | 叶或邵岚提到梁在整期中的关键决定，许有机会补全，选择只补无关痛痒的一点。读者看清她正在做什么，不能只写“她的话有两层意思”。 |
| 80 | 闻曼递来的位置 | 闻提出分开创意与日常管理，由许承担更多统筹。许知道这会削弱梁的接班方案，仍接下进一步论证；闻的提议出于自身布局，不是看穿所有人的万能安排。 |
| 81 | 你替我答应了什么 | 梁从实际安排发现自己的管理职责被缩减，当面追问许。许承认参与分工建议，两人围绕真实贡献和未来权力争执，不靠一句误听就决裂。 |
| 82 | 她也有别的地方可去 | 梁接触外部工作室机会，认真评估租金、团队和项目来源。陆愿跟随，但要谈岗位与费用；离开不是愤怒时喊出来的一句豪言。 |
| 83 | 谁跟谁走 | 团队成员分别考虑留下或出去，许争取关键人员，梁也不会白送自己的信任资源。有人拒绝许的挽留，有人选择薪水稳定，人员不是两位上司的所有物。 |
| 84 | 下次还是这批人吗 | 季需要判断下一次已获批采访与拍摄的执行条件，许已知道关键人员可能离开，却强调班底能够维持。她暂不说尽的事实足以影响他的推荐，亲密被实际用作信用。 |
| 85 | 她想先拿到任命 | 许面对补充说明的机会仍选择等架构确定再说，想先保住副主编窗口。季据此向内部支持安排；这一次她主动让别人替自己的不确定性承担风险。 |

### 岑音线必须修正的具体内容

- **等待五小时：** 写拍摄超时，原约采访被推迟，陆在酒店走廊吃冷盒饭等人；不能写成岑音“临时停工”而不交代谁在干什么。
- **旧标题：** 清样仍是《岑音，不必证明》。陆曾提出中性的角色方向替代，未被接受；不再出现已经删掉“不必证明”、实际旧清样却没变的矛盾。仅换题不解决正文把她写成放下的偏差。
- **补访问法：** 陆担心许为换机会答应删原有的选戏失误，许说明未承诺，提出补问之后如何选戏。没有根据时不写“她本人可能要改口”。
- **试演视频：** 岑音仍在争未确定的角色，自己录一段表演给导演，想用演法说明对结尾的理解；不是已经接戏后莫名其妙反复试镜，也不以资深演员无需试戏为前提发问。
- **改稿给出原句：** 如“终于肯承认想拿奖”暗示原先否认，删成准确问答；如结尾替她解释“用新戏回应失奖”，就问她是否真说过，没有便以实际试演和等待回复收尾。不写“几个有劲判断”“两个意思”却不给内容。
- **管理问责有依据：** 上周只核片名年份、奖尚未揭晓的许，没有义务提前发现整篇人物方向失效。闻问她如何判断能补访，不凭空追责；九年经验的记者也不能靠连续犯低级错来衬托上级。
- **陆的威胁感有实物：** 新署名、对外接触和下一次机会改变，才触发她的不满。她可以明确说前期投入被忽视，不能把许已承认合作的一声谢谢硬解释成抢功。

### 临川展冲突的边界

演员不是拿专访或纸刊位置交换登台，许也不许诺自己无权保证的版面。主办用不同口径制造了困局：上台可能被当成认可新品，退场又被写成耍大牌。品牌方、主持与执行知情程度分别交代，不把所有人设成同谋。

许的信息来自正常采访与对方愿意提供的材料，不偷看完整私密合同，不碰巧在角落听到全部阴谋。她先向报社说明核实到的事实、争取采访支持，再推动有权负责人处理现场；不以“不给专访就曝光”敲诈。纠正的范围必须实在：撤误导物料、删除推荐语、澄清加价说法，主办或品牌让出部分宣传收益并承担关系成本。具体舞台流程起稿时核对可执行性，不把一句主持补充当成网上所有误导立刻消失。

老演员在看见许如何采访后愿意多谈，许写出能成立的内容，再向报社争取半个版面。程综合现场表现和成稿推荐面试；演员愿受访、报社给版面、程愿推荐是三个不同决定，不能自动连锁兑现。

## 七、生活、感情与时间的写法

生活不按固定“每隔几章休息一次”机械插入。表中第6、17、28、38—41、48、56、59、68、72、87、96、98、115—118、129、137—139、147、149、158—160章等处，已有独立生活或亲密场景；它们占用全书既定字数，不作为额外扩写配额。

- **赵佳线：** 从租屋吃烧烤、逛市场失约，到普通周末和反向照料，维持一段能笑、能生气、也能修复的圈外友谊。她不必每次都替许指出道德问题。
- **住处和消费：** 房租三千六的新城市起点，与后来换住处、衣着和付账习惯对照。不是每次升级都暗示堕落，也不是只写穷苦才有真实感。
- **季与许：** 交易、期待、恋爱、披露调整、甜蜜、控制和隐瞒、分手、各自承担损失、重新选择，顺序清楚。甜蜜期必须让人愿意相信他们真的爱过；后期复合不恢复原来的资源交换。
- **陈与许：** 有过真实过去；工作正常付费；明确单身后短暂亲密，再因人生安排不同结束。无需牺牲陈的人格完成男女主团圆。
- **叶与周、唐与贺：** 用少量生活场景呈现先前的好与后来安排的不同，不为写够长篇各加一套出轨、婚变或家庭疾病。
- **时间推进：** 四年不是每周都出大事。通过系列下一期、季节、租约、假期和岗位稳定后的日常自然跨月；不把所有职业成长挤在几周里，再用一句“三年后”兑现管理能力。

## 八、职业与叙事的底线

以下为小说既定虚构结构与权限，保留V7的核心约束，压缩重复制度说明；不是对所有真实媒体的现行制度作概括。

1. 《浮华》由境内期刊出版单位出版并聘用采编，经营业务由另设的品牌服务公司承接。采编不背广告销售指标，不拿广告提成，许不靠一个大客户的订单直接升主编。
2. 经营、编辑、视觉制作、出版审读各有实际决定者。采访事实核实不自动等于对方拥有整篇否决权，改稿也不能跳过必要审校。开篇48小时以文件尚未放行、内页可替换及备用稿已具备条件为前提。
3. 稀缺采访有对象、时间和范围。季能影响引介与媒体安排，不承诺全球永久独家、任命或封面；私下偏向真实存在，做出好内容不使其自动无害。
4. 男女主第二卷申报现阶段关系、调整对接，不追溯洗去初期隐瞒；调查按已证事实处理。机构不知道的完整性交易仍是读者知道的事实，证据增加必须同步改变后果。
5. 专题职责、副主编、代理管理与正式主编分别成立，审读签发按实际资格和授权承担。正式任命来自有权机构，不由国际合作方、广告客户或一个荐人单独许诺。
6. 素材、署名、照片、样衣、离职作品与预算各有边界。正文只写影响当前胜负的事项；不能把版权核对、交接、付款全部当成独立情节。
7. 争执不能凭作者追加“其实还有另一层意思”成立。指控、反击、改稿、让步尽量给出读者能看见的内容；含蓄用于加深已经明白的关系，不代替基本事实。
8. 晋升要有成果和时间，伤害要有具体对象与失去的东西。对手不会为女主赢集体失智，朋友不会因一次感谢自动恢复；也不规定她每次成功必须伤一个女人。
