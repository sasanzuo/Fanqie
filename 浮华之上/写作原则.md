# 《浮华之上》写作原则

适用于全部续写、重写与校订。依据前五章试读 V1—V3 的修订与作者确认形成；不是只针对开篇的临时要求。

## 一、行业真实与人物判断

- 按虚构期刊社已确立的机构、岗位、权限与生产流程推进。采访、编辑、视觉制作、审校签发和经营业务各有责任人；女主的能力不能替代其他专业人员的工作。
- 对撤稿、审稿、素材使用、署名、预算、岗位和晋升等冲突，写清具体约定、谁能决定、谁承担责任。区分对方提出要求、双方已有约定、编辑部自主取舍与真正的越界，避免把强势人物的要求直接写成行业规则。
- 艺人团队要求撤稿，不自动等于杂志依法不能发；核对事实不等于获得全文否决权；照片、引语与其他素材的使用范围分别处理。具体争议依据小说已交代的约定与事实判断，不将一种虚构安排泛化为所有杂志的惯例。
- 新人获得机会需要实际授权、内部阻力和合理分工。原作者贡献、共同采访、审读责任和后续对接分别交代，一次救火不自动带来长期管理权。
- 情节涉及奖项、作品、服装借用、版权及人事等专业细节时，补足影响理解的必要背景；拿不准的关键事实先核实。
- 通过工作场景与选择呈现规则，避免把小说写成制度说明书。各方有独立利益，专业人士可以判断失误、越界或伤害别人，但不为女主取胜集体失去常识。
- 女主保持聪明、隐忍、有手段、有野心的核心。她能伤害别人、感到愧疚并继续争取；不要将所有损害都解释成被迫或正当防卫。

## 二、对话、叙述与节奏

- 每段对话应推进信息、冲突、关系或人物选择。对已明确的条件不反复确认；一般流程和不影响争执的往返用叙述归纳。
- 保留真正的利益交锋、试探、拒绝与含混，删掉礼貌应答和机械问答形成的拖沓。精简不等于让人物句句都是金句。
- 删减没有信息增量的“看了一眼、抬头、低头、拿起、放下、停了停”等动作。动作应体现权力、压力、迟疑、隐瞒或现场变化；不要为了避开重复，另换一套同样空泛的动作。
- 降低“没有……只……”“没再……”“不愿……”等否定式的连续密度，能直接写发生了什么，就直接写。保留有真实心理意义的否定，尤其是女主有意不做某件事的选择，不机械清零。
- 用自然段组织场景，避免无必要的一行一句、旁白复述对白，以及在场景末尾替读者归纳人物道理。

## 三、人物声线与出场

人物声线由岗位、经历、关系和当下状态形成，不只靠口头禅区分。

| 人物 | 主要声线及表达方式 |
| --- | --- |
| 许照宁 | 有目的、会试探、能忍；根据对象调整说法，重要信息会选择保留。聪明通过准备与取舍体现，不靠总能说中核心的长篇总结。 |
| 梁映真 | 简短、偏管理判断，明确任务、时限和分歧交给谁；专业意见落在具体内容，避免每次都展开教学。 |
| 陆蔓 | 从原采访、稿件句子、素材和实际投入反击，重视署名与关系主导；有真能力，不只负责酸言酸语。 |
| 钟妍 | 客气的公关措辞、缓冲、回避和试探，可能迟迟不给实质答复；不会每次直接坦白全部顾虑和底线。 |
| 岑音 | 公开访谈与私下补访可以不同；允许停顿、找词、改口、答非所问或收住一句话，避免每次都完整阐释自己。 |
| 叶知微 | 相对自然、坦诚，有具体生活细节与专业边界；帮助女主，也有自己的创作与利益，不充当全知解释者。 |
| 苏禾 | 重视具体事项与执行，涉及人际风险时会谨慎、求确认；不因递来线索就突然掌握完整内情。 |
| 闻曼 | 关注稿件判断、人才用途和整体安排，选择性追问，保留决定空间；与梁映真的具体执行口吻区分。 |

- 重要人物首次参与情节时，自然交代职务、负责事项及与女主的工作关系。
- 控制同时引入的姓名和职务数量。次要人物先以职务出现，待承担关键行动时再落姓名；不要要求读者背人物表才能读懂场景。
- 同一人物面对上级、同事、受访者与亲近的人可以有不同表达，不把声线固化成单一模板。

## 四、每次续写与校订的执行方式

1. 先读本原则、对应大纲和最新正式章节，核对时间、已有分工、关系变化及各人实际知道的信息。
2. 写作中按上述原则选择情节和表达，不留到完稿后只做词语替换。
3. 完稿后检查：权责及流程是否成立；对白是否重复；动作与否定式是否扎堆；人物是否人人说得同样准确；新姓名是否造成阅读负担。
4. 正式内容直接更新“正式正文”的分章 Markdown。试读和合订稿保留各自历史状态；新确认的长期原则同步维护本文件。
