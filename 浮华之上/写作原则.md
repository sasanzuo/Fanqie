# 《浮华之上》写作原则

适用于全部续写、重写与校订。依据前五章试读 V1—V3 的修订及后续作者确认持续更新。

最近更新：2026年10月23日。按作者最新要求，全书约20—22万字，暂按160章重分；增加断章，不扩充故事体量。原单章1500—2000字要求由本轮总量与章节目标取代。具体人物动机、开篇校订与全书任务见当前大纲V8。

## 一、行业真实与人物判断

- 按虚构期刊社已确立的机构、岗位、权限与生产流程推进。采访、编辑、视觉制作、审校签发和经营业务各有责任人；女主的能力不能替代其他专业人员的工作。
- 专业人员已有的判断与局部方案应保留。女主可以界定混淆、补上缺失信息或找到沟通入口，不把所有专业问题都改成只有她能理解、解决。
- 有职业经验的人在书面沟通中也会为自己保留解释空间，不能为方便反击写成主动自证。区分原话、他人转述和主观理解，结合权限、完整语境与实际后果判断，不让一张截图直接替代复盘。
- 对撤稿、审稿、素材使用、署名、预算、岗位和晋升等冲突，作者需掌握具体约定、决定权与责任。正文只交代影响本场取舍、胜负和后果的必要信息，其他流程简述；区分要求、约定、自主取舍与真正的越界，避免把强势人物的要求直接写成行业规则。
- 艺人团队要求撤稿，不自动等于杂志依法不能发；核对事实不等于获得全文否决权；照片、引语与其他素材的使用范围分别处理。具体争议依据小说已交代的约定与事实判断，不将一种虚构安排泛化为所有杂志的惯例。
- 新人获得机会需要实际授权、内部阻力和合理分工。原作者贡献、共同采访、审读责任和后续对接分别交代，一次救火不自动带来长期管理权。
- 情节涉及奖项、作品、服装借用、版权及人事等专业细节时，补足影响理解的必要背景；拿不准的关键事实先核实。
- 具体冲突必须让读者看清：各方要什么、卡在哪个要求、失败有什么后果；女主依据哪些可获得的信息发现问题，提出什么方案，谁批准、谁执行、谁作出让步。能力通过可见行动及结果展示，避免用“她指出分歧”“后来他们谈妥”等概述跳过关键过程。
- 通过工作场景与选择呈现规则，避免把小说写成制度说明书。各方有独立利益，专业人士可以判断失误、越界或伤害别人，但不为女主取胜集体失去常识。
- 女主保持聪明、隐忍、有手段、有野心的核心。她能伤害别人、感到愧疚并继续争取；不要将所有损害都解释成被迫或正当防卫。

## 二、对话、叙述与节奏

- 采访涉及录音时，自然交代受访者知情同意；不机械延伸成每场都重讲授权。
- 每段对话应推进信息、冲突、关系或人物选择。对已明确的条件不反复确认；一般流程和不影响争执的往返用叙述归纳。
- 保留真正的利益交锋、试探、拒绝与含混，删掉礼貌应答和机械问答形成的拖沓。精简不等于让人物句句都是金句。
- 删减没有信息增量的“看了一眼、抬头、低头、拿起、放下、停了停”等动作。动作应体现权力、压力、迟疑、隐瞒或现场变化；不要为了避开重复，另换一套同样空泛的动作。
- 降低“没有……只……”“没再……”“不愿……”等否定式的连续密度，能直接写发生了什么，就直接写。保留有真实心理意义的否定，尤其是女主有意不做某件事的选择，不机械清零。
- 同一问题已由邮件或对话交代，后续没有新增争议时不再完整复述；用停发照片、延期采访、空出的版位等具体后果推动情节。避免让程序词替代场景。
- 情节动作足以表达心理时，删去场景后的第二轮解释。重要的心理矛盾保留一层，不在同章反复替读者总结。
- 用自然段组织场景，避免无必要的一行一句、旁白复述对白，以及在场景末尾替读者归纳人物道理。

## 三、人物声线与出场

人物声线由岗位、经历、关系和当下状态形成，不只靠口头禅区分。

| 人物 | 主要声线及表达方式 |
| --- | --- |
| 许照宁 | 有目的、会试探、能忍；根据对象调整说法，重要信息会选择保留。聪明通过准备与取舍体现，不靠总能说中核心的长篇总结。 |
| 梁映真 | 简短、偏管理判断，明确任务、时限和分歧交给谁；专业意见落在具体内容，避免每次都展开教学。 |
| 陆蔓 | 从原采访、稿件句子、素材和实际投入反击，重视署名与关系主导；有真能力，不只负责酸言酸语。 |
| 钟妍 | 客气的公关措辞、缓冲、回避和试探，可能迟迟不给实质答复；不会每次直接坦白全部顾虑和底线。 |
| 岑音 | 公开访谈与私下补访可以不同；允许停顿、找词、改口、答非所问或收住一句话，避免每次都完整阐释自己。 |
| 叶知微 | 相对自然、坦诚，有具体生活细节与专业边界；帮助女主，也有自己的创作与利益，不充当全知解释者。 |
| 苏禾 | 重视具体事项与执行，涉及人际风险时会谨慎、求确认；不因递来线索就突然掌握完整内情。 |
| 闻曼 | 关注稿件判断、人才用途和整体安排，选择性追问，保留决定空间；与梁映真的具体执行口吻区分。 |

- 重要人物首次参与情节时，自然交代职务、负责事项及与女主的工作关系。
- 人物先以职务出现、后正式落名时，用简短提示建立对应关系；间隔数章再出现且身份影响理解时，适当重带职责。出版责任编辑与版面制作等相邻岗位不得混称，不让读者靠猜认人。
- 控制同时引入的姓名和职务数量。次要人物先以职务出现，待承担关键行动时再落姓名；不要要求读者背人物表才能读懂场景。
- 同一人物面对上级、同事、受访者与亲近的人可以有不同表达，不把声线固化成单一模板。

## 四、前后衔接与大纲一致性

- 每次写作都必须与前续正式正文衔接、对齐，并核对整体走向是否符合当前大纲。这是起稿前和完稿后的必做步骤，不凭对话记忆或旧试读印象接写。
- 起稿前至少读相邻前章、当前段落对应大纲，以及涉及的人物或事件最初确立的章节；有跨章回收时向前查原文。一般续写以当前正式正文为已发生事实，旧试读只供修订历史参考。明确启动重写或重新规划时，先标明哪些正文待按新大纲校订，不把规划中的变化当成已经写成的事实；新旧章号须分别定位。
- 核对时间、地点、事件先后、物件状态、人物职务和称呼、已有授权与分工、关系变化，以及每个人当时知道和不知道的信息。回忆段也要与现在线的照片、消息、推荐及面试经过对得上。
- 新人物需在真正参与情节时交代身份；已出现人物不能当成首次见面。职位称呼转为姓名应有清晰对应，不能一会儿是责任编辑，一会儿又承担排版人员的身份。
- 每章应推进大纲规定的阶段任务，不提前消耗后续反转、职务变化或感情节点，也不靠新增情节悄悄推翻已确立事实。确需调整走向时，明确记录原因并同步相关设定。
- 修改前章后，向后核对受影响的正式章节；修正因果与称呼，更新版本入口，保留历史快照，避免新旧文本混读。

## 五、每次续写与校订的执行方式

1. 先按第四节查阅本原则、对应大纲及前续正式正文，确认衔接基准和本章推进任务。
2. 写作中按上述原则选择情节和表达，不留到完稿后只做词语替换。
3. 完稿后先复核上下文一致性与大纲走向，再检查：单章是否按自然变化断开、是否符合当前全书字数预算；本章是否产生信息、局势、关系或情绪的实际变化；媒体外行能否看懂利益、陷害与后果；关键胜负是否兑现；流程说明是否过多；生活及私人欲望是否得到呈现。同时核对人物身份、权责逻辑、重复对白、空泛动作、否定式密度、人物声线与新姓名负担。
4. 正式内容统一维护作品目录指明的当前合订Markdown，以章标题区分内容，避免不同正文入口并存。作者可直接改正文或在附近写【修改意见：……】，按交稿提交与作者提交的差异修订；直接修改默认保留，批注落实后清理。历史试读与重写前存档保持原状态，新确认的长期原则同步维护本文件。

## 六、通俗网文表达、章节与生活

### 1. 冲突通俗、行动明确、胜负可见

- 本书按通俗网文的阅读体验组织叙事。读者应直接看懂谁想得到什么、谁在阻拦、用了什么手段、对方失去什么，以及女主如何应对；不要求读者先理解媒体行业的细分岗位、术语及内部流程。
- 陷害、抢功、甩锅、排挤和反击要有具体动作与后果。不能只靠含混说法、几次眼神和事后解释，让读者自行拼出有人在害人。人物可以否认恶意，正文仍需让读者识别其有意的行为。
- 读者与女主掌握的信息可以不同。通过女主可见的行为、后续查明的事实或明确的视角切换呈现设局，保持叙事视角一致，不用不实内心独白隐瞒她已知的事实。
- 专业逻辑用于支撑行动。采访授权、审校签发、邮件抄送、素材核对及版本流转，只保留影响本场冲突的必要细节；常规办理一笔带过，同一事项不按会议、邮件、执行、复盘反复展开。
- 冲突紧凑，并由人物利益推动。合作、嫉妒、设防、隐瞒与主动害人均须有原因、获利预期及风险；不能为增加戏剧性，让角色主动破坏自己急需的共同成果。
- 关键胜负在场景中兑现：谁得到认可、谁丢掉主导权、谁取得机会、谁承担损失。细微动作可加深意味，不能独自承担整场高潮。
- 女主可以主动利用信息差、时机和他人弱点反击，也会借冲突扩大自己的机会。保留其野心与攻击性，不把每次算计都解释成完全被迫。

### 2. 全书约20—22万字，更多分章而不扩写

- 作者最新目标为150—200章、总字数仍在20万字上下。当前按160章、约21万字规划，控制在20—22万字；不因为章数增加而把目标扩至三十万字。此为本书写作约定，不宣称是平台统一发布规定。
- 160章对应平均每章约1250—1375字，取代原每章1500—2000字目标。多数章节1100—1500字，完整交锋可到1600—1800字，少数确有自然落点的短章可在1000字左右结束；这些是执行参考，不是必须填满的模板。
- 主要通过拆分既有故事、删去重复说明和调整场景落点改善阅读。每章应使信息、局势、关系、选择或情绪至少一项发生实际变化，在能引起后续期待的节点结束，不在完整句子中间硬切。
- 同一场面拆为多章时，各章须有不同的推进。一个提问、等待回信、收到普通通知、转发材料、重复心理判断，均不能仅为了凑章数独立成章；不要求每章都有反转。
- 每卷按当前大纲核对累计字数，超支先删流程复述、二次解释和同功能场面，不删决定胜负的必要交锋。相邻章没有独立变化就合并，最终在作者允许的150—200章范围内调整，总量目标不随之放大。

### 3. 工作之外的生活

- 持续安排住处、通勤、吃饭、朋友、消费、休息及亲密关系等生活场景，与工作冲突形成节奏变化。让读者看见许照宁下班后怎样生活，在亲近的人面前是什么样子。
- 生活包含快乐、幽默、欲望、虚荣、松弛和普通烦恼，不只用剩吐司、加班与房租证明她辛苦。具体爱好、私人关系和新配角在后续设计中确立，不将讨论中的例子直接当成既定设定。
- 私人交往应有双方的生活与诉求，不能所有聚餐都变成开会，所有朋友都只提供线索或解释职场。生活本身可以承担人物塑造与情绪变化。
- 一轮工作胜负后，留出消化成果、承受损失或处理私人关系的空间；生活也可以改变下一次选择，不机械规定固定比例。

## 七、本轮校订补充：意思写到具体内容上

- 叙述涉及等待、停工、删改、让步或反悔，要交代谁做了什么、原来约定什么、后来变了什么。不能用一个含混动词掩盖不同的事实关系。
- 重要改稿争执给出必要的原句与改后意思，读者应看懂删掉了哪种判断、为什么会歪曲人物；不要只说“删了最有劲的判断”“收尾替她说”。普通改字不必逐项展示。
- “两层意思”“暗流”“听出了提醒”只能加深已明确的关系，不能代替事实。人物的警告、嫉妒和责问要有当场行为或既有分工作依据，不因作者想埋冲突就强加动机。
- 问责必须对应人物当时承担的任务、掌握的信息和实际决定权。不让上级凭空敲打，也不让有经验的主角连续犯低级错，为别人制造教学机会。
- 每个持续工作场景必须有尚未完成的具体任务。已经交接的排期、已经结束的联系人沟通不重复安排；确有新任务才重启，不以办手续填章节。
- 重要的能力展示写出可见的发现、核实、顶住压力、推动决定和结果，按情节选必要环节，不机械逐项铺开。人物只能使用合理取得的信息，不能靠一眼看穿所有人、碰巧拿到全部证据或一句提醒赢得过量回报。
- 同一事件的采访机会、发表版面、职位推荐和最终任用是不同决定，各需相应人物的判断，不能一次帮助自动兑换全部奖励。具体人物和事件如何成立，记入大纲，不写成通用人物设定。
